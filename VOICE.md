# Reel voiceover + background music

Voice: offline Hindi neural TTS (Piper "pratham" male voice via sherpa-onnx). Works in the cloud workspace without any API key.
Music: original royalty-free track generated by tools/music.py (soft pads + gentle beat) – no copyright issues.

## Setup (once per run)
```
pip install "sherpa-onnx==1.12.40" soundfile --break-system-packages   # 2.x can't phonemize Hindi – keep 1.12.40
mkdir -p /home/claude/voices && cd /home/claude/voices
curl -sSLO https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-piper-hi_IN-pratham-medium.tar.bz2
tar xjf vits-piper-hi_IN-pratham-medium.tar.bz2
```
(Other voices: vits-piper-hi_IN-priyamvada-medium = female, vits-piper-hi_IN-rohan-medium = male.)

## Per reel
1. Write the voiceover in **Devanagari** (the Hindi voice can't read Roman script). Write English words and numbers
   phonetically in Devanagari: "एन सी एम सी", "पच्चीस प्रतिशत", "रियल एस्टेट", "खंडेलवाल रियल्टी". Short sentences, commas for pauses.
   Save it as YYYY-MM/<date>-<slug>.voiceover.txt. Aim for 22–28 s.
2. `python3 tools/tts.py /home/claude/voices/vits-piper-hi_IN-pratham-medium <script.txt> /tmp/vo.wav 1.0` → prints the length L.
3. `python3 tools/music.py <L+3> /tmp/bg.wav`
4. Scene length d so the video covers the voice: total = n*d − (n−1)*0.5 ≥ L + 2 → d = (L + 2 + (n−1)*0.5) / n.
5. `python3 reel.py templates/<reel>.html <n> YYYY-MM/<file>.mp4 <d> /tmp/vo.wav /tmp/bg.wav`
6. Check with ffprobe that there are both video and audio streams.
